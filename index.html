Вопросы

Сколько стоит Silk?

Нисколько. Silk бесплатный и без рекламы.

Windows пишет «Система Windows защитила ваш компьютер». Что делать?

Установщик пока не подписан сертификатом, поэтому Windows его не узнаёт. Нажми «Подробнее», потом «Выполнить в любом случае». Прав администратора установка не просит.

Нужен ли аккаунт?

Чтобы слушать музыку, не нужен. Аккаунт нужен только для друзей: войти можно через Google, GitHub, Discord или почту.

Откуда берётся музыка?

Silk ищет и проигрывает треки с площадок: YouTube, SoundCloud, Spotify, Яндекс Музыка, VK и других. Для Яндекс Музыки и VK нужен твой аккаунт на этих сервисах.

Что Silk знает обо мне?

Без аккаунта ничего: библиотека, настройки и история лежат только на твоём компьютере. Что хранится, если войти в аккаунт, написано на странице Конфиденциальность.

Как удалить аккаунт?

В Silk открой «Друзья», нажми «Изменить профиль», затем «Удалить аккаунт» и ещё раз для подтверждения. Профиль, друзья, лайки, история и твои плейлисты сразу стираются с сервера.

Есть ли версия для iPhone?

Пока только Windows 10 и 11. Версия для iPhone в работе.
